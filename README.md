# Sherlock

Sherlock analyzes Bitcoin Core block data from `.dat` files.

## Required files

You must provide all three files together:

- `blkNNNNN.dat`
- `revNNNNN.dat`
- `xor.dat`

`blk` and `rev` must have the same numeric suffix (for example: `blk04330.dat` + `rev04330.dat`).

## How users obtain the `.dat` files

These files come from a local Bitcoin Core data directory (they are not generated by this project).

1. Install and run Bitcoin Core.
2. Let the node sync.
3. Open the network's `blocks` directory and locate:
	- a matching `blkNNNNN.dat` + `revNNNNN.dat`
	- `xor.dat`
4. Upload those three files into Sherlock.

### Default Bitcoin Core paths

#### Mainnet

- Windows: `%APPDATA%\Bitcoin\blocks`
- Linux: `~/.bitcoin/blocks`
- macOS: `~/Library/Application Support/Bitcoin/blocks`

#### Testnet

- Windows: `%APPDATA%\Bitcoin\testnet3\blocks` (or `testnet4\blocks`)
- Linux: `~/.bitcoin/testnet3/blocks` (or `testnet4/blocks`)
- macOS: `~/Library/Application Support/Bitcoin/testnet3/blocks` (or `testnet4/blocks`)

## Notes

- If your node is pruned (`prune` enabled), only recent `blk/rev` files are available.
- If `xor.dat` is missing in your setup, use an 8-byte zero-filled file named `xor.dat`.
